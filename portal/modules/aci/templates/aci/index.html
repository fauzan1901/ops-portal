Fabric interfaces

Every port of every leaf on site : what uses it (vPC, port-channel, interface policy, static paths) and what is connected. Pick ports for a static port or a new vPC. Read-only: nothing is changed on APIC.

NodeInterface StateUseConnected toStatic pathsDescriptionActions
Tick ports, then add them to Static Port; a port in a vPC or port-channel adds its vPC or port-channel.

vPC pairs

The vPCs of each pair of leaves, and the ports free on both leaves: candidates for a new vPC.

Create vPC

A new vPC on a pair of leaves of site : a vPC interface policy group and its interface selector, as in Fabric > Access Policies on APIC. Then the vPC path can be bound to EPGs on Static Port.

This changes the access policies of the fabric. The portal only adds a policy group and a selector; it never changes or deletes one that exists. Everything is shown on the Review screen and checked on APIC again before it is sent.
Your account can review a new vPC, but not create it. An administrator can allow it on the Users page (ACI: create vPCs).
